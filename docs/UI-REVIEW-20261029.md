# 花开有声：界面评审与整改

## 结论与方法

本轮针对2026-10-29验收站第4版（Follower 4a985b5）做Impeccable独立双评审：A判断设计与阅读路径，B独立收集机械与浏览器证据。先完成A再合并detector输出，避免锚定。结论是保留深靛蓝光场和完整原作，修复顺序、分组和组件状态。

评审前启发式评分29/40，是专家判断，不是真实用户满意度或WCAG认证。状态3、认知匹配3、控制3、一致性2、错误预防3、识别3、效率3、美学3、恢复3、帮助3；各项满分4。没有虚构整改后的更高分数。

## 已整改

| 原问题 | 优先级 | 最终行为 |
|---|---|---|
| 手机详情视觉在上、键盘先跳到下方 | P1 | DOM和手机统一为标题、展台、简介与操作；桌面保留左右栏 |
| 首页当前作品与故事入口分离 | P2 | 当前作品旁提供“读作品故事”，展名旁保留首屏“开始观展”；两者随切换同步 |
| 标注仅可聚焦li、Tab即改内容 | P2 | 原生按钮，Enter/Space激活；图片与文字选中状态同步aria-pressed |
| 收藏色态跨页反转 | P2 | 未收藏描边、已收藏青绿实底；统一悬停、键盘焦点 |
| 备份下载/撤销/历史工具同级，初始空色块 | P2 | 下载与恢复分区，旧版工具折叠，预检后才出现确认；零新增不显示提交动作 |
| 768宽扫描点击区22px、指南窄三列和低对比标签 | P2 | 扫描最小44px，指南<=1000宽采用单列，删除重复小标签 |

首页移动端曾出现“主入口移出首屏”的回归；146项珠光回归发现后，通过双入口分工修复，未放宽该验收断言。

## 验证证据

- 181项单测通过；本地相关浏览器检查407项：详情125、展览与备份63、珠光146、核心质量51、切换22。
- 原有回归覆盖图片/模型/音频失败、原作保留、重试、减少动态、收藏、导入确认和撤销；新断言检查手机顺向Tab、标注键盘激活、扫描44px、预检前不出现确认及两个作品入口同步。
- B独立浏览器核验768指南单列、扫描44x44、390详情Tab顺序及标注Enter/Space，使用Edge；IAB当时不可用。
- 第一次检查24组视口无页面级横向溢出。修改后由上述测试和限定浏览器复核验证；不扩张为所有设备/浏览器通过。
- detector前后均10条：6条旧album阴影已由运行样式覆盖、4条noscript静态上下文。逐项解释，未把静态告警当运行缺陷；没有注入可视覆盖层（浏览器evaluate只读）。
- 本地截图、检查JSON、两个独立报告和收尾评审位于 reports/ui-review-20261029/（忽略的本地验收证据）。最终首页截图由Chromium等待图片解码后保存，浏览器原生取证与最终截图来源分别记录。
- 未新增或修改图片资产、未改变花册数据契约、未开启相机。真机扫描、独立用户试用与正式服务器验收仍不在本轮通过范围。
