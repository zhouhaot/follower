# 首页切换连续性修复

用户在1033×870预览中反馈切换黑屏，并要求取消光影按钮、默认开启效果。

修复前用延迟图片请求复现：旧图已被移除，新图尚未加载，整个主卡片opacity为0.35。修复后等待新图decode成功才提交作品名、链接与选择状态；新图320ms叠化，旧图在其下方完整保留。慢请求不会覆盖较新的选择，失败时保留当前作品并可再次选择重试。背景canvas只在实际尺寸变化时重设尺寸，并在同一回调补绘。

移除首页“演示光影”和光场开关；背景默认响应输入，珠光就绪时自动演示一次约1.6秒，随后静止。离屏、后台及系统减少动态效果仍停止非必要动态。未更改原作、故事或音频。

本机验证：181项单测；切换专项22/22，含逐动画帧的已解码图像/实际2D像素可见性和背景清屏补绘状态；1033、390、320三宽度；快速重复、键盘、错误恢复、减少动态。现有光场/备份57/57、珠光集成146/146。全套云端结果另列发布记录；不沿用旧提交CI结果。

未改正式服务器，main不合并，更新现有草稿PR与Sites验收站。

云端PR检查曾发现失败图片的提示可能被旧作品稍晚完成的光影初始化覆盖。现将切换反馈与渲染反馈分开，增加受控延迟的确定性用例，验证重试提示保留；修复后专项22/22通过。
