## 给参与者的任务（一次只展示一条）

1. 你第一次来到这个页面。请说说你认为这里可以做什么，然后选择一张感兴趣的花卡，了解它的故事。
2. 你希望以后还可以找到这张花卡。请用你认为合适的方法留下它。
3. 回到首页，再找到刚才留下的花卡。
4. 关闭当前标签页，在同一浏览器重新打开首页，再找一次。
5. 请判断这个版本是否能听到故事。如果不能，你还能怎样完成这次体验？

补充任务（核心任务完成后再做）：浏览另一张花卡，只阅读不收藏，随后查看花册，描述两张花的记录有什么区别。

## 主持人观察规则

- 先记录参与者的原话与实际操作，再写解释；不要把自己的推断写成反馈。
- 记录首个选择、回退、误点、犹豫位置及是否求助。参与者求助时先问“你原本期待会发生什么”。
- 需要提示才能继续时如实标记“辅助完成”，不要计为独立完成。试用可随时停止。
- 不录入个人敏感信息；使用匿名编号。未取得许可不录音、不录像、不向他人发送记录。
- 推荐后续安排 3–5 名不熟悉项目的人作定性观察；这只是安排建议，未开展招募。
