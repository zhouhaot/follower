# 本地业务闭环：实现、使用与来源记录

这是当前候选的实际应用层开发记录，不是登记申请书、作者声明或权属证明。内部开发版本为 0.5.0，尚未发布。没有填写登记作者、发表日期或其他未经确认的事实。

## 需求与新增范围

用户明确要求在 Three.js、MindAR 等库以外增加真实可用的业务功能，为将来的软件材料准备提供基础；不凑行数，不把第三方代码改名计为原创，不提交登记申请。本轮没有恢复双手建模，没有安装 Blender，没有调整首页或手部构图。

原候选已经具有图录、详情、扫描状态机、收藏写入、手部序列和五款花卉模型。本轮不将它们重复描述为新增。实际新增的是两个闭环：

1. **本地导览**：建议路线或自选顺序 → 保存 → 从详情页明确标记已看 → 下一站 → 刷新继续 → 完成或重新开始 → 撤销上一步。参观记录与识别收藏互不代替。
2. **收藏备份与恢复**：下载带校验值的 JSON → 本机文件预检 → 显示新增/重复记录 → 用户确认 → 只合并缺少项 → 保留导入前恢复点 → 撤销；有后续数据变化时拒绝覆盖。

## 操作与可核验证据

- 从 `guide.html` 点击“安排我的本地导览”，或直接打开 `journey.html`。选择建议路线，或在五个位置选择不同花卡并保存。在详情页点击“标记这张已看”，可继续下一站。这个操作不会请求相机，也不会增加收藏。
- 从 `collection.html` 点击“备份与恢复本机收藏”，或打开 `backup.html`。下载 JSON 后可在另一个浏览器使用；导入前必须看到预检，再勾选说明并确认。新增记录标为“历史备份恢复 · 非本次识别”，不会被显示为本次扫描成功。
- 导入时同名本机记录优先，保留原时间和来源。重复文件不产生额外写入。仅有一层撤销恢复点；下一次成功操作会更新这一恢复点。
- 导览存储使用 `flowers-speak:visit-route:v1` 及其日志键。收藏仅使用原候选键和新增导入日志键，不读取或迁移生产网站的未知存储格式。
- `npm test` 包含原有测试和新增业务测试；`node tests/business-browser.mjs` 使用独立后台 Chrome、1440/390/320 像素视口及合成记录，不操作用户当前收藏或真实相机。截图中的注入字符串是安全测试内容，不是用户资料。
- 当前报告：`reports/qa/business-unit-tests.tap` 与 `reports/qa/business/business-audit.json`。本轮结果分别为 143/143、71/71。实际恢复验证及两份快照的大小、SHA-256 在任务的 `local-deliverables/` 中单独记录。

## 数据与失败路径契约

- 备份 v2 包含格式名、目录版本、导出时间、至多五条规范记录和平台 SHA-256。这个校验值仅用于发现意外损坏，既不是身份认证，也不能证明文件里的历史扫描真实发生。
- 兼容输入为当前候选已有的 `{version:1, entries:[...]}` 收藏数据；预检明确提示 v1 到备份 v2 的迁移。确认前不写入，未知未来版本及不同目录版本均保留而不覆盖。
- 文件最多 65,536 字节；在读取前检查 File.size，读取后验证 UTF-8 和 JSON，并再次按 UTF-8 字节数限制。拒绝原型污染字段、未知字段、未知/重复花卡、错配目标索引、非图像识别方法、无效日期等。
- 用户输入通过 textContent 写入 DOM，不把路线名或文件名作为 HTML、URL、脚本或样式执行。不上传文件、不引入服务器、账号、统计或云同步。
- 恢复点先写入并读回核验，再保存主数据。主数据写入失败时尝试恢复原始字节；无法确认回滚则明确报错并保留恢复点，不冒称成功。
- 预检确认前和日志保存后会核对主数据；撤销也要求当前值与导入后记录相同。检测到其他页面变化时要求重新预检，不能用旧计划覆盖新记录。localStorage 不是数据库事务，这一机制是乐观冲突保护，不宣称跨进程强事务隔离。
- 新增的收藏来源标记会在原读取/后续其他卡识别写入时保留。原识别写入器增加了未知/损坏存储格式保护，避免在新记录写入时默默清空不认识的数据。

## 应用层代码与第三方边界

| 文件 | 本轮作用 | 来源说明 |
|---|---|---|
| `public/business-data.mjs` | 目录身份约束、输入规范化、数据边界、错误消息 | 本轮 AI 辅助编写的项目应用逻辑；引用现有卡牌身份，SHA-256 使用浏览器标准 API |
| `public/local-transaction.mjs` | 本地日志、保存核验、冲突检测、撤销与失败恢复 | 本轮 AI 辅助编写的项目应用逻辑 |

| `public/collection-backup.mjs` | 备份协议、旧格式迁移、预检、合并与撤销 | 本轮 AI 辅助编写；保留历史来源标记 |
| `public/business-ui.mjs` | 纯文本 DOM 控件工具 | 本轮 AI 辅助编写；不是第三方 UI 库 |
| `public/journey-page.mjs` / `public/backup-page.mjs` | 真实页面交互与错误状态 | 本轮 AI 辅助编写的页面逻辑 |
| `public/business.css` / 两个新 HTML | 现有博物馆风格中的业务界面 | 本轮新增，首页 CSS 和首页模板不改 |
| `public/app.mjs` / `collection-store.mjs` | 接入入口、恢复来源显示及旧存储保护 | 在已有项目应用代码上修改；不将整个原模块算成本轮新增 |
| `tests/business-tools.test.mjs` / `business-browser.mjs` | 数据、回滚、注入、隐私及实际操作测试 | 本轮 AI 辅助编写；只用合成数据 |
| `scripts/backup-business.py` / `start-local-preview.py` | 版本快照核验、回环预览运行 | 本轮辅助工程工具，单独列示，不伪装为核心业务功能 |
