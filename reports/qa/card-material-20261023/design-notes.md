# 莲花卡材质探索：实现记录

日期：2026-10-23。范围：`public/card-material.html`、`public/card-material.css`、`public/card-material.mjs`、`public/card-material-renderer.mjs`。

本文件按 Impeccable document 的扫描方法记录已实现值，供本次样稿交接使用，不是全站设计规范。用户批准的是同一张莲花卡的「纸本压纹 / 局部珠光」比较，尚未选定其中一版作为整站系统。项目根目录此前没有 `PRODUCT.md` 或 `DESIGN.md`；本轮不创建它们，也不生成全局 token 或组件 sidecar。

## 方向与继承

沿用已确认的当代博物馆数字展览方向，以 Experience 模式让作品居于中心。深绿展陈背景、轻量工具栏与等条件比较服务于材质观察。两版使用相同的 `assets/originals/lotus/target.png`（884 × 1255）、相同展示尺寸和同一题名，`object-fit: contain` 保留完整纹样。未重绘、裁切或替换原画。

标题与卡片题名继续使用既有 `assets/fonts/exhibition.ttf`，字体名为 `Exhibition`，回退为 `'Songti SC', serif`；正文字体栈为 `'PingFang SC', 'Microsoft Yahei', sans-serif`。页眉保留首页、莲花故事和完整印刷花卡入口；完整原作指向 `assets/originals/lotus/card-named.png`。纹样来源文案沿用原项目的“都江堰市博物馆《荷花图》”，本轮没有独立核实或新增馆藏、历史断言。

## 材质差异与深度

| 实现维度 | 纸本压纹 | 局部珠光 |
| --- | --- | --- |
| 主视觉 | 暖纸底、细颗粒、浅边缘起伏 | 浅冷卡框、局部清蓝与月白反光 |
| 表面细节 | 程序化 grain / fiber，叠加原图邻域变化形成的法线扰动 | 保留较弱 grain 与浮雕明暗，并叠加随角度移动的光带 |
| 原图推导 | `relief` 对 RGB 最大分量做 `smoothstep(0.045,0.48,…)`，采样左右上下邻域；是明暗近似，不是实测高度图 | 以蓝、绿、浅色区域及亮度阈值生成 mask；不是逐花瓣手工分区或语义识别 |
| 反光范围 | 漫反射细节为主 | 在 mask 内混合窄光带、宽光带、掠射和高光；深色背景、粉饰与金点不作整面反光罩 |
| 颜色处理 | 原图基础上施加轻微暖色系数 `vec3(1.012,1.,0.982)` | 原图基础上叠加受限的冷色干涉近似，保留原作颜色可辨认 |

两版各自用正交相机渲染平面，复用同一套自定义 WebGL shader，通过 `uPearl` 选择材质。CSS 透视为 1100px，卡片倾斜最大为 Y 轴 ±13°、X 轴 ±10°；背面边缘位于 `translateZ(-3px)`。纸本投影为 `2px 3px 0 #a69e8d,8px 22px 36px #080e0c70,1px 2px 4px #08130e50`；珠光版仅把第一层边缘色改为 `#a5afa8`。这些是数字收藏品的视觉深度，不等于实体厚度或真实印刷参数。

两候选均为数字视觉近似，不宣称真实纸张、压纹工艺、物理精确薄膜干涉或可直接交付印厂的效果。

## 交互与可访问边界

- 默认不自动播放。鼠标移动、横向触摸拖动、方向键改变角度；方向键每次步进 `.18`，归一化范围为 `[-1,1]`，Home 或「归正」回中。鼠标离开卡片回正；触摸正常抬手保留角度，取消事件回正。`touch-action: pan-y` 保留竖向滚动。
- 「演示光影」仅运行一次 1800ms 往返扫描，结束回正；两版共用演示角度。「查看原图」同步隐藏两版 canvas，切换按钮通过 `aria-pressed` 表达状态；返回材质后恢复按需绘制。至少一版准备好才启用原图比较，原图模式禁用演示和归正。
- 卡片可聚焦，提供键盘说明和图片替代文本；状态使用 `role="status"`，装饰 canvas 对辅助技术隐藏。减少动态效果时卡片静止、关闭过渡并隐藏演示及归正按钮，仍可切换材质与原图。
- 使用既有按需帧队列；空闲不持续绘制。原图模式、页面隐藏或卡片离屏停止绘制；页面离开时取消队列，非缓存离开还释放资源。像素比例上限 1.5，WebGL 使用 `low-power`，不启用抗锯齿。
- 材质模块、图片、WebGL 或上下文丢失时显示失败状态；原图可用则保留原图，原图本身失败则明确提示刷新重试。无 JavaScript 时保留两张原图与说明。每版独立准备，不把一版失败当成两版成功。
