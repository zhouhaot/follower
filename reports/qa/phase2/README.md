# 第二阶段浏览器证据

本目录是 2026-10-23 的本地隔离验收，不是真人试用。主结论见 [阶段报告](../../../PHASE-2-REPORT.md)。

- `phase2-browser.json`：四种尺寸的首次进入、阅读、收藏、再次找回、键盘与可选入口返回检查。
- `1280 / 768 / 390 / 320` 前缀 PNG：每种尺寸的 `home`、`detail`、`collection`、`catalogue` 全页截图。
- `regression/phase1-browser.json`：原有存储正常与异常路径的当前版本回归。
- `regression/first-run-locator-error.json`：首轮测试定位冲突原始记录。
- `unit-tests.txt`：单元测试原始输出。
- `build-verification.json`、`verified-files.json`：构建对照与源文件摘要。
- `design-detect.json`：设计扫描的两条字体提示，处理说明见阶段报告。
